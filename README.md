# MoodMind ✦

An AI-powered journaling app that analyzes your mood from what you write and gives personalized suggestions.

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express
- AI: Google Gemini API
- Database: Supabase (coming soon)

## Status
🚧 In development — built as a learning project

## Setup
1. Clone the repo
2. Run `npm install` in both `/frontend` and `/backend`
3. Add your Gemini API key to `backend/.env`
4. Run backend: `npm run dev` (inside /backend)
5. Run frontend: `npm run dev` (inside /frontend)
